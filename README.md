<h1 align="center">Projeto em Grupo com Git e GitHub</h1>

<p align="center">
  Projeto desenvolvido em equipe para a disciplina de <strong>Qualidade e Testes de Software</strong>: Um site no qual cada integrante ficou responsável pela criação de pelo menos uma página específica. O projeto utiliza diferentes <strong>branches</strong> para organização do desenvolvimento, além de <strong>pull requests</strong> e <strong>merges</strong> para integração das funcionalidades à branch principal.
</p>
